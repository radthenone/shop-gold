Uwierzytelnianie dwuskładnikowe (2FA) zwiększa bezpieczeństwo Twojego konta, wymagając dodatkowego kodu podczas logowania.

Aby skonfigurować 2FA, potrzebujesz aplikacji takiej jak Google Authenticator, Microsoft Authenticator lub Authy na swoim urządzeniu mobilnym.
